# 체커 🔴

컴퓨터와 하거나 방 코드로 친구와 실시간 대결하는 체커(영국식 드래프트). [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다.

- 8x8 판의 어두운 칸에만 말을 둔다. 양쪽 12개씩, 빨강(아래, 먼저)과 파랑(위). 말(맨)은 대각선 **앞으로 한 칸**
- 앞 대각선에 상대 말이 있고 그 뒤 칸이 비어 있으면 **뛰어넘어 잡는다**. **잡을 수 있으면 반드시 잡아야 하고**, 잡은 뒤 또 잡을 수 있으면 같은 말로 이어서 잡는다(연속 뛰기, 칸을 차례로 눌러 가며). 맨은 뒤로는 못 움직이고 못 잡는다
- 맨이 끝 줄에 닿으면 👑 왕. 맨이 뛰어서 끝 줄에 닿으면 왕이 되고 그 차례는 끝난다. 왕은 대각선 앞뒤 어느 쪽으로든 한 칸 가고 잡는다
- 상대 말이 모두 잡히거나 더 움직일 수 없으면 이긴다. 잡거나 맨을 움직이지 않고 **80수**(양쪽 40번씩)가 지나면 무승부
- 조작: 내 말을 눌러 고르면 갈 수 있는 칸이 노랗게 표시된다. 칸을 누르면 이동(연속 뛰기면 다음 착지 칸을 이어서 누른다). 같은 말을 다시 누르면 취소. 움직일 수 있는 말은 위아래로 흔들린다. 내가 파랑이면 판이 뒤집혀 내 말이 늘 아래에 온다
- 컴퓨터: 쉬움은 35% 는 아무 수나 두고 나머지는 2수 앞만 보며, 어려움은 4수 앞(사람이 이길 만하게 예전 6수에서 낮춤)을 본다 (말 수·왕·앞으로 나간 정도·가운데·뒷줄을 평가하는 알파-베타 탐색). 어려움이 쉬움을 거의 이긴다 (시험으로 확인)
- 컴퓨터를 이긴 횟수는 `checkersWins` (로비 표시용), 온라인 전적은 `checkersOnline`
- **온라인 대전**: 빠른 대전 · 4글자 방 코드(초대 링크 `?room=코드`) · 재접속(30초) · 한 수 60초(넘기면 시간패) · 기권 · 한 판 더(빨강·파랑 교대). 서버가 같은 규칙(`public/logic.js`)으로 모든 수를 검사하므로 차례가 아니거나 규칙에 어긋난 수(잡기를 빼먹는 수 포함)는 무시한다. 방 코드를 짧은 시간에 많이 틀리면 잠깐 막는다
- M 소리

규칙과 컴퓨터는 `public/logic.js`(화면 없이 Node 로 시험할 수 있다), 화면·입력·소리·온라인은 `public/game.js`, 방·매칭은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(규칙·컴퓨터 — **시작 판에서 가능한 수의 개수(perft)가 영국식 드래프트의 알려진 값 7·49·302·1469·7361·36768·179740 과 같다**, 더 깊이(8단계 845,931, 9단계 3,963,680)도 따로 확인), `test/server.test.js`(서버를 띄워 한 판을 끝까지 두는 흐름·입력 검사·시간 초과·재접속 등).
